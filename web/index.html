About VenomMaps (USA)

VenomMaps (USA) is a simple, fast map to help you figure out which venomous snakes are likely around you in the United States. It’s designed for quick, practical use — whether you’ve just arrived somewhere new, you’re planning a trip, or you’re simply curious about your area.

What you’ll see
  • Range areas: shaded regions showing where each species is known to occur.
  • Sightings (optional): recent reports you can turn on when you want more detail.
  • Nearby (in view): a quick list of species that likely occur in the map area you’re looking at.
  • Search by name: find snakes by common or scientific name.
What’s included here
  • Focus on the U.S.: this map shows venomous snakes native to the United States.
  • Pitvipers only: we include rattlesnakes, copperheads, and cottonmouths. Coral snakes are not shown here to keep the map focused and simple.
  • Clean, fast data: ranges are tuned for speed and clarity, and sightings are off by default so the map loads quickly.
How this differs from the original VenomMaps
  • Purpose: this version is built for quick “what’s around me?” answers with minimal clicks.
  • Scope: U.S. species only, with a simpler set of layers; the original covers many more species and regions worldwide.
  • Interface: fewer controls and a cleaner layout so it’s easier to use on the go (works well on phones — rotate to landscape for more room).
  • Sightings: you choose when to turn them on; when enabled, the map shows broader patterns when zoomed out and individual points as you zoom in.
Tips for getting the most out of the map
  • Pan and zoom to your area, then check the Nearby (in view) list.
  • Hover or tap the map to see species names where ranges overlap.
  • Use the Search bar to jump to a species you’re interested in.
  • Turn on Sightings if you want to see recent reports; use the time chips (7d, 30d, etc.) to narrow it down.
Important note

Maps are guides, not guarantees. Snakes can occur outside shaded areas, and data can be incomplete. Always keep a safe distance and follow local guidelines.

        Historical heat map

        This layer is a smoothed density map built from all historical sighting points. Each point adds a small circular bump in screen pixels; where many bumps overlap, the map looks hotter. This is essentially a kernel density estimate (KDE).

        Value(x) ≈ Σ w_i · K(||x − x_i|| / r)
K: radial kernel (circular)
r: radius in pixels (≈18px with blur)
w_i: point weight (intensity)

        Data and weights:

        • Input file: web/data/heat_all_r6.geojson with Point features.
        • Each feature becomes [lat, lng, intensity] for Leaflet.heat.
        • Intensity is log‑compressed so dense spots don’t dominate.
        // map.js (excerpt)
const features = geo.features;
const step = features.length > 50000 ? Math.ceil(features.length / 50000) : 1; // downsample
for (let i = 0; i < features.length; i += step) {
  const f = features[i];
  if (!f || f.geometry?.type !== 'Point') continue;
  const [lng, lat] = f.geometry.coordinates;
  const count = (f.properties && typeof f.properties.count === 'number') ? f.properties.count : 1;
  const intensity = Math.max(0.2, Math.min(1, Math.log(1 + count) / 3));
  points.push([lat, lng, intensity]); // [lat, lng, weight]
}
L.heatLayer(points, {
  radius: 18,
  blur: 15,
  maxZoom: 11,
  minOpacity: 0.25,
  gradient: { 0.2:'#1e3a8a', 0.4:'#2563eb', 0.6:'#f59e0b', 0.8:'#ef4444', 1.0:'#dc2626' }
});
        • Downsampling preserves hotspot shape; we can rescale intensity if exact totals matter.
        • Pixel radius means smoothing adapts with zoom (coarser out, finer in).
        • Global view: species selection and time chips don’t affect this layer.
